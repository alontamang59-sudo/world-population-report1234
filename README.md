# World Population Reporting System

## Description
This project is a C# application that connects to a MySQL World database and generates population reports.

## Technologies Used
- C#
- .NET
- MySQL
- Docker
- GitHub

## Features
- Top 10 Countries by Population
- Countries by Continent
- Countries by Region

## How to Run
1. Start Docker:
   docker compose up -d

2. Open ReportApp:
   cd ReportApp

3. Run:
   dotnet run
